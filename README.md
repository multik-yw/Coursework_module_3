# Курсовая работа

## Описание:
Разработка приложения для анализа банковских операций клиента.

## Установка проекта:
1. Клонировать репозиторий:
- https://github.com/multik-yw/Coursework_module_3
2. Установите зависимости:
- pip install -r requirements.txt

## Структура проекта
## 1. src\reports.py:
- Функция **save_to_file()**:
  Принимает список транзакций и искомую категорию и создает отчет о тратах в данной категории.
- Функция **spending_by_category()**:
  Возвращает траты по заданной категории за последние три месяца.
## 2. src\services.pу:
- Функция **simple_search()**:
  Возвращает JSON со всеми транзакциями с искомой строкой в описании.
## 3. src\utils.py:
- Функция **greeting_function()**:
  Функция возвращает приветствие в зависимости от текущего времени суток.
- Функция **read_excel()**:
  Функция возвращает данные о финансовых транзакциях из файла excel.
- Функция **get_sum_by_card()**:
  Возвращает данные по каждой карте.
- Функция **get_top_five()**:
  Возвращает топ-5 транзакций по сумме платежа.
- Функция **get_exchange_rate()**:
  Возвращает курсы валют.
- Функция **stock_prices()**:
  Возвращает стоимость акций.
## 4. src\views.pу:
- Функция **web_main()**:
  Функция страницы Главная.

## Тестирование проекта
Все тесты находятся в директории "test". 
В папке "htmlcov" в файле "index.html" находится отчет по тестированию проекта в HTML.
